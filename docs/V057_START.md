# Start here (v0.5.7)

Players: give them the player ZIP ("Cry of Fear Co-op v0.5.7.zip"). Each runs
"Install.cmd" (game closed), then double-clicks "Run Co-op Mod.cmd". The host
clicks "Host Simon's Story" (the game's Create Server window: chapters, saves,
players, difficulty, collision); a friend clicks "Join Simon's Story" (a box
for the host IP and port). R skips a cutscene. "Uninstall.cmd" puts
everything back.

This developer folder also has README.md (changes), TESTING.md (the test run),
release.json, known-builds.json and the adapter source.
