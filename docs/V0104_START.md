# Start here (v0.10.4)

Players: give them the player ZIP ("Cry of Fear Co-op v0.10.4.zip"); Linux players the
"Cry of Fear Co-op v0.10.4 Linux.tar.gz" (bash coop.sh). Each opens
"Cry of Fear Co-op.exe" and clicks Install (game closed), then Run Co-op Mod.
The host clicks "Host Simon's Story" (the game's Create Server window: chapters, saves 1-5, players,
difficulty, collision, doors that change the map wait for everyone (on), Unlock extras, revive time,
auto respawn, and the v0.10 options, all off: run timer, outlines, monster scaling, hunted, hardcore,
morphine time, no hints); a friend clicks "Join Simon's Story". "Player Model" picks your model and
hands. R skips a cutscene, K gets you unstuck, H hides the HUD, T sprays, G pings, J scares, Q drops a
box of your gun's ammo. SETTINGS and SPRAY in the launcher set the view, the keys, your colour, black
and white, your light and the spray picture. Uninstall puts everything back.

This developer folder also has README.md (changes), TESTING.md (the test run),
release.json, known-builds.json and the adapter source.
