# Start here (v0.9)

Players: give them the player ZIP ("Cry of Fear Co-op v0.9.zip"); Linux players the
"Cry of Fear Co-op v0.9 Linux.tar.gz" (bash coop.sh). Each opens
"Cry of Fear Co-op.exe" and clicks Install (game closed), then Run Co-op Mod.
The host clicks "Host Simon's Story" (the game's Create Server window: chapters, saves 1-5, players,
difficulty, collision, Unlock extras, revive time, auto respawn); a friend clicks "Join Simon's Story".
"Player Model" picks your model, and Done there goes on to your hands. R skips a cutscene, K gets you
unstuck, H hides the HUD, T sprays. SETTINGS and SPRAY in the launcher set the view, the keys and the
spray picture. Uninstall puts everything back.

This developer folder also has README.md (changes), TESTING.md (the test run),
release.json, known-builds.json and the adapter source.
