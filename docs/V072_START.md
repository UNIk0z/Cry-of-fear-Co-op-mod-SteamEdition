# Start here (v0.7.2)

Players: give them the player ZIP ("Cry of Fear Co-op v0.7.2.zip"). Each opens
"Cry of Fear Co-op.exe" and clicks Install (game closed), then Run Co-op Mod.
"Install.cmd" and "Run Co-op Mod.cmd" do the same steps. The host clicks "Host
Simon's Story" (the game's Create Server window: chapters, saves 1-5, players,
difficulty, collision, Unlock extras); a friend clicks "Join Simon's Story".
"Player Model" picks your model. R skips a cutscene. Uninstall puts everything
back.

This developer folder also has README.md (changes), TESTING.md (the test run),
release.json, known-builds.json and the adapter source.
